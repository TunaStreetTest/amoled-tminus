# amoled-tminus

T-MINUS — a true-black launch clock for the Waveshare
ESP32-S3-Touch-AMOLED-1.8 V2. Counts down (or up) to the next real rocket
launch, stepping through Launch Library 2's upcoming window.

## Runs on

An [ESP-Brookesia](https://github.com/espressif/esp-brookesia) v0.8 runtime
JS app for the [`waveshare-devices`](https://github.com/TunaStreetTest/waveshare-devices)
platform image (Waveshare ESP32-S3-Touch-AMOLED-1.8 V2). The package here
installs onto the board's LittleFS partition via that repo's
`amoled-1.8-v2/tools/stage_apps.py` — apps are files dropped into `apps/`,
not a firmware rebuild.

## Backend

FastAPI, port `8092`, no API keys required:

```bash
bash scripts/run.sh
```

Env vars:

| Var | Default |
|---|---|
| `TMINUS_VENV` | `/home/tunas/tuna-starlink-app/backend/.venv` — needs `fastapi`/`uvicorn`/`httpx`/`pydantic` |

Endpoints:

| Endpoint | Shape |
|---|---|
| `GET /health` | `{ok, app: "tminus"}` |
| `GET /tminus/now` | `{id, vehicle, mission, pad, t0_unix, server_unix, status, idx, count}` |
| `POST /tminus/step` | body `{"dir": 1\|-1}` → same shape, steps to the next/previous launch |

`backend/launches.py` polls [Launch Library 2](https://ll.thespacedevs.com/)'s
`upcoming` endpoint, keeps an 8-launch window, and defaults to the next
launch that hasn't lifted off yet. Cached 15 minutes upstream-side.
`server_unix` rides on every payload because the board's QuickJS `Date` can
be epoch-0 — the clock ticks off the server clock plus a local 1s timer.

## Layout

```
apps/tunastreet.tminus/   the runtime app package (manifest.json, app/, res/)
backend/server.py         FastAPI backend
backend/launches.py       Launch Library 2 client + upcoming window
scripts/run.sh            start the backend
```

## Gestures

Swipe left for the next launch, right for the previous one. Vertical swipe
is never intercepted — it stays the platform's home gesture.

## How the screens are built

Screens under `res/screens` are generated by the panelkit design system in
`waveshare-devices/amoled-1.8-v2/uikit` and linted by that repo's
`tools/simulator/lint.js` before anything ships to the glass — never
hand-edited. The generator scripts live outside this repo. Launch
vehicle/mission/pad text is ASCII-folded before it reaches the panel: the
board's built-in LVGL font is ASCII-only, so an unfolded en-dash or curly
quote renders as a blank box on the glass.

## Sandbox notes

Plain global QuickJS script (`JS_EVAL_TYPE_GLOBAL`): no `fetch`, no `XHR`,
no `setTimeout`. HTTP via the platform's `Http` service (async, with a
synchronous fallback), timers through `SystemTimer`, UI mutation through
`SystemGui`.
